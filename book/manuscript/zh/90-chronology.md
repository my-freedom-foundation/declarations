# 附录A　精选时间线

*《以人民之名：特权、革命与不受约束的权力》· 中文初稿 v0.2 · 2026年9月17日*

这份年表选取全书讨论的三十五个历史节点，把身份、授权、组织权力与公众问责放回时间中。日期沿用正文及共同来源记录的精度；事件、文件通过、后来的回顾与材料公开分别标明。每行末尾可进入相应来源记录，再追溯所据文本。

| 编号 | 日期 | 事件与本书关注的问题 | 来源定位 |
| --- | --- | --- | --- |
| C01 | 1662年12月 | 弗吉尼亚殖民地法律规定，当地出生的孩子依母亲身份为自由人或被奴役者。身份由此成为可以跨代延续的支配条件。 | [第1章 B01](93-notes.md#ch01-b01) |
| C02 | 1765年10月19日 | 印花税大会决议主张，殖民地税收须经本人或其代表同意，并要求通过当地代表机关征税。这是与会代表提出的权利主张。 | [第2章 C01](93-notes.md#ch02-c01) |
| C03 | 1776年7月2日、4日 | 大陆会议先于2日通过独立决议，再于4日通过《独立宣言》文本。宣言把政府的正当权力系于被统治者的同意；文本通过与其后羊皮纸本的签署过程不同。 | [第2章 C03](93-notes.md#ch02-c03)、[C04](93-notes.md#ch02-c04) |
| C04 | 1777年1月13日 | 兰开斯特·希尔、普林斯·霍尔等署名的请愿书，向马萨诸塞湾议会要求被奴役者的自由。自由原则被用于质问独立后的社会；请愿本身还不是生效法律。 | [第2章 C09](93-notes.md#ch02-c09) |
| C05 | 1789年8月26日 | 法国《人权和公民权宣言》提出权利平等与公共利益等原则，为检验身份差别提供公开标准。 | [第1章 B04](93-notes.md#ch01-b04) |
| C06 | 1791年9月3日 | 法国宪法规定“积极公民”及选举人产生的资格。初级集会参与资格包含直接税和身份条件，说明宣布平等与平等参政之间仍有距离。 | [第1章 B05](93-notes.md#ch01-b05) |
| C07 | 1848年 | 马克思、恩格斯的《共产党宣言》以阶级关系解释社会冲突，提出改造所有制与集中生产工具的政治方案。本书由此追问，代表劳动者掌握资源的人如何受劳动者约束。 | [第4章 EQ02](93-notes.md#ch04-eq02)、[EQ03](93-notes.md#ch04-eq03) |
| C08 | 1863年1月1日 | 林肯发布《解放宣言》，以战时权限宣布指定叛乱地区被奴役者自由，并承诺联邦支持。它有地域豁免，实际落实需要军事保护，并非当日全国无条件废奴。 | [第3章 A07](93-notes.md#ch03-a07) |
| C09 | 1865年8月7日 | 乔登·安德森在致前奴隶主的信中提出过去劳动的工资账目，并询问子女安全与教育。信记录他的要求，不是获得赔偿的凭证。 | [第3章 A01](93-notes.md#ch03-a01) |
| C10 | 1865年12月6日 | 美国第十三修正案达到所需州的批准门槛；国会此前于1月31日通过。修正案禁止奴隶制及非自愿劳役，保留依法定罪后的刑罚例外，并授权国会执行。 | [第3章 A09](93-notes.md#ch03-a09) |
| C11 | 1921年3月16日 | 俄共（布）十大通过《关于党的统一》决议，要求解散派别，同时规定党内批评渠道。组织统一与劳动者自主表达之间的张力，成为第4章的收束问题。 | [第4章 EQ09](93-notes.md#ch04-eq09) |
| C12 | 1948年12月10日 | 联合国通过《世界人权宣言》，提出平等、有效救济、公正审理和政治参与等标准。本书将其作为衡量权力的规范参照。 | [第12章 L02](93-notes.md#ch12-l02) |
| C13 | 1949年6月30日 | 毛泽东《论人民民主专政》说明“人民”的政治分类、共产党的领导与对敌人的强制。谁有权划定人民的范围，成为理解新政权的入口。 | [第5章 S02](93-notes.md#ch05-s02) |
| C14 | 1953年11月19日 | 政务院通过粮食计划收购和计划供应命令，规定粮种、价格、数量及逐级任务；正文落款为11月23日。这些规定把国家的分配权同家庭生计直接联系起来。 | [第5章 S05](93-notes.md#ch05-s05) |
| C15 | 1954年9月20日 | 中华人民共和国宪法通过，写入人民权力、群众监督、独立审判、迁徙自由及控告、赔偿等规定。条文承诺与个人能否实际使用权利，需要分别考察。 | [第5章 S03](93-notes.md#ch05-s03) |
| C16 | 1958年1月9日 | 《户口登记条例》通过并公布。农村居民迁往城市的迁出手续须有录用、录取或准迁证明之一；这不同于禁止一切出行。 | [第5章 S06](93-notes.md#ch05-s06) |
| C17 | 1959年7月14日 | 彭德怀致信毛泽东，对大跃进提出意见。他仍支持大跃进和公社方向；信及其后笔记呈现内部批评者希望纠正政策的立场。 | [第5章 S07](93-notes.md#ch05-s07) |
| C18 | 1966年8月5日、8日 | 按王晶垚后来声明所述，卞仲耘于5日在北京师大女附中遭殴打致死。8日中共中央通过文革《十六条》，其中同时规定党的领导及人民内部说理、保护不同意见的要求。遇害早于该决定。 | [第5章 S10](93-notes.md#ch05-s10)、[S11](93-notes.md#ch05-s11) |
| C19 | 1974年7月24日 | 美国最高法院在尼克松案中裁定，本案总统的一般保密主张不能压倒刑事审判中具体证明的证据需要；材料须先交地区法院非公开审查。判决体现有边界且可执行的司法约束。 | [第12章 L04](93-notes.md#ch12-l04) |
| C20 | 1978年12月22日及年底 | 22日通过的中共十一届三中全会公报提出扩大经营自主权，同时保留统一计划及党的领导。小岗村包干到户契约形成于年底，确切签订日未在本书确定；现有材料既未确定二者的先后关系，也未将它们确认为同一项政策。 | [第6章 R01](93-notes.md#ch06-r01)、[R02](93-notes.md#ch06-r02) |
| C21 | 1981年6月27日 | 中共通过《关于建国以来党的若干历史问题的决议》，承认庐山批判、反右倾及文革中的错误。它是党的事后评价，不是全部受害经历的独立调查。 | [第5章 S08](93-notes.md#ch05-s08) |
| C22 | 1982年1月1日、12月4日 | 1月1日中央批转农村工作会议纪要，明确承认多种生产责任制，保留土地集体所有。12月4日通过并公布的新宪法对国家主席、副主席等特定职务规定连续两届上限；这一上限没有适用于总书记或军委主席。 | [第6章 R03](93-notes.md#ch06-r03)、[R06](93-notes.md#ch06-r06) |

| C24 | 1989年6月3日至4日 | 军队沿北京西部道路推进并向市民开枪。美国驻北京使馆6月22日电报记录这些行动，混合不同知情层次；丁子霖证言记录儿子蒋捷连于3日深夜在木樨地中弹的遭遇，她并未亲眼见到枪击。 | [第6章 R09](93-notes.md#ch06-r09)、[R10](93-notes.md#ch06-r10) |
